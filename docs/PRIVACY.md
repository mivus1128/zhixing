# 隐私与数据边界

## 仓库中不包含

- 资金账号、交易密码及其真实遮罩值。
- 模型服务或验证码服务的 Key。
- Cookie、浏览器 profile、券商登录证明和验证码样本。
- 账户余额、持仓、成交、委托或策略归档。
- 服务器 IP、SSH 凭据、个人电脑路径和生产日志。

仓库中的账号、标的、接口和 Key 样例均为测试夹具，并使用明显虚构的值或 `.invalid` 保留域名。

## 部署后会产生

网页中填写的外部服务配置、券商凭据、账户快照、运行状态和策略归档会写入 Docker 的 `runtime` 或 `archives` 卷。它们不在源码目录中，也不会因重新构建镜像而进入 Git。

浏览器登录态存在于浏览器容器的可写层，重建浏览器容器后可能需要重新登录。不要导出浏览器容器或 profile 并上传到公开仓库。

## 发布前检查

```bash
python scripts/check_public_tree.py
git status --short
git ls-files
```

确认 `.env`、备份、日志、运行卷导出文件和浏览器数据均未被跟踪。若真实凭据曾进入 Git 历史，仅删除当前文件不够：应立即在服务端轮换凭据，并清理尚未公开的 Git 历史后重新扫描。
